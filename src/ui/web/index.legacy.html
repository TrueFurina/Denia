🌐 云端双工·用户自有端点（缓解公共端口抢不到）
公共免费端点常被占满/排队。可分别在下方填你自己的语音、视频双工网关（完整 wss URL，含 host:port 与 ?mode=）。两者都留空则用官方默认。

无显卡设备本地起不来 → 自动全程云端，无需配置。
⚠️ 本地全双工推理时约占用 6~11GB 显存（取决于量化档位），会与游戏、剪辑等吃显存的软件争抢资源； 玩大型游戏或跑重负载软件时建议切回云端（0 资源占用）或关闭双工。
想下大的下大的、想下小的下小的：选好点「下载」会自动拉取并写入配置（重启引擎生效），也可点「魔塔链接」手动下。

GPT-SoVITS 语音克隆配置
本地克隆服务的地址：GPT-SoVITS 默认 9880 端口，VoxCPM2 默认 9881 端口
点击"浏览"在电脑里选音频，或直接粘贴绝对路径（.wav，3~10秒，清晰人声）
选 2~3 段不同语气的语音（日常/慵懒/关心），多段融合后说话更"有感觉"；不填则只用主参考
MiniMax 语音配置（云端，不占本地显卡）
云端合成音色，低性能设备也能用克隆音色。需要去 platform.minimaxi.com 注册拿 API Key（有免费额度，超出自费）。
每个人填自己的 key，费用由使用者承担
点击输入框右侧下拉箭头选择系统音色（少女/御姐/甜美等），或直接输入 MiniMax 平台复刻音色的 id（克隆达妮娅本音：平台上传语音生成复刻音色后，把复刻音色 id 填这里）。更多音色见 platform.minimaxi.com 文档
从本地音频克隆新音色（快速复刻）
上传你的录音即可克隆出同款音色，克隆成功后自动回填到上方音色框，保存角色即可使用。需要平台已完成实名认证
小米 MiMo 语音配置（云端·限时免费·不占本地显卡）
小米 MiMo-V2.5-TTS 语音克隆，中文顶级、限时免费（超出自费）。去 api.xiaomimimo.com 注册拿 API Key（跳过 Bearer 前缀，直接粘 Key）。上传一段达娅录音即可克隆同款声线，每句直接带上参考音合成，无需单独复刻步骤。
每个人填自己的 key，费用由使用者承担；小米说改收费就收费，可随时换其它克隆引擎
点击"浏览"在电脑里选音频，或直接粘贴绝对路径。建议 10~30 秒清晰干声，声线还原更稳
填好 Key + 达娅录音后点这里，用当前设置念一句给你听

🎙️ MiniMax 接入向导

1. 注册账号

用手机号注册 MiniMax 开放平台，新用户赠送 15 元体验金（够克隆 1 个音色 + 合成几百句）。注册后请完成实名认证（个人认证，几分钟通过）——复刻音色必需，不认证克隆会报 2038。

2. 获取 GroupId

在「账户信息」页找 GroupId / 用户组 字段（纯数字，个人账号 = UID）。复制后粘贴到下面：

3. 创建 API Key

在「接口密钥」页点「创建新的 API Key」。Key 只在创建时完整显示一次，请立即复制完整内容（不要带 Bearer 前缀）粘贴到下面：

4. 克隆音色（可选）

选一段 10 秒~5 分钟 的干净录音（mp3/m4a/wav，≤20MB），克隆你的专属音色。想先快速用起来就「跳过」用系统音色（少女/御姐/甜美等）。

克隆成功后自动回填音色并进入下一步（首次合成时收取复刻费 9.9 元）

5. 完成！

点「测试连接」：能播放出声音就说明全部配置完成。之后给角色选「MiniMax 语音」引擎、保存角色，就能用克隆音色说话了。
