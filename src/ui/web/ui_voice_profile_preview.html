发声开关（与配置分开）

「本地克隆 / 云端 TTS」不是这个开关的选项 —— 它是新建音色档时的"方式"选择。开关只管"响不响"，方式归配置，两者不互相绊。

我的模型配置（打字 / 聊天）
「多套并存」= 保留多条端点配置，像浏览器里存了多个书签：平时用智谱免费档、想强推理切 DeepSeek、断网切本地 Ollama —— 切一下即可，不用重填 Key。（你 config 里 text_chat.providers 本来就是 4 套的数组）
