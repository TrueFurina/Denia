软件专属陪伴 · 设计规范

把"知识库/专属陪伴提示词"这类工程师术语，统一改成达妮娅第一人称、普通人能秒懂的陪伴语言；卡片视觉贴合极光青紫设计语言。

一、重做后的档案卡片
左侧新增极光渐变脊（青→紫，呼应品牌色）；每张卡片的陪伴文案上方加了 达妮娅陪你 小标题，把"知识内容"框定为她的陪法，角色口吻更明确。

三、设置页「游戏陪伴方案」编辑器
真实 app（app.js）里的游戏陪伴编辑器已同步人话化：占位「专属陪伴提示词：描述陪伴风格…（双工模式下注入模型上下文）」→「达妮娅怎么陪你：写写她该留意画面里的什么、用什么语气跟你聊、什么情况别打扰」。保存提示「双工立即生效」→「达妮娅下次陪你玩这个游戏就用新方式啦」。
