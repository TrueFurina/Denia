怎么让达妮娅更懂你正在用什么软件 / 玩什么游戏

?什么是知识库

知识库让你按「软件 / 游戏」给达妮娅添加专属背景知识。写进去之后，当你把这个软件全屏或最大化沉浸使用时，达妮娅会自动切换成更懂这个场景的陪伴方式——知道该留意什么画面、用什么语气陪你。平时小窗切来切去不会打扰你。

内置条目可以直接编辑（覆盖默认），用户新增的条目也可以彻底删除。内置和用户的区别用卡片右上角的小标签标注。

1主要字段怎么填

知识内容
按三段式写：【领域关注】画面元素 + 该留意什么 → 【建议 / 优先级】多事件时先说哪个、何时闭嘴 → 【表达风格】语气 + 禁忌。短而准比一大段攻略更管用，太长它反而记不住。点「+ 领域模板」可一键起手。
画面关注（可选）
写它通常长什么样——界面布局、常见元素。不是写软件百科。达妮娅靠这个看准你屏幕，不乱编。
表达风格（可选）
陪聊语气和分寸、别碰什么。比如「背景音乐只是氛围别评价」「别把输入法皮肤当表情包」。
怎么触发
只有把该软件全屏 / 最大化沉浸时才会切换陪伴方式（小窗不触发，避免来回跳）；切走几秒自动恢复通用。切换时右上角弹窗会跟着真实连接状态走：正在连 → 连上啦 （绿条）→ 自动收起。

2陪伴模式：双工 vs 快照 + OCR

新增软件时有一个陪伴模式下拉，决定达妮娅怎么「看」这款软件：

双工（默认）
真全双工：带上下文、能听声音、每秒看画面。适合视频、聊天、IDE这类没有固定文字、靠语义理解的场景，开口最自然。
快照 + OCR
事件驱动：不靠模型自由发挥，只响应你框定区域里出现的文字再开口（仿三角洲游戏的 OCR 陪伴方案）。适合能稳定显示固定文字的软件——比如状态栏、进度、报错、结算横幅。配合下方「OCR 识别区块」使用。

怎么选：软件界面里有没有「一出现某个词就该说话」的固定文字？有 → 选快照 + OCR（更准、不抢戏）；没有、全靠理解画面 → 选双工。

3OCR 识别区块（文字 → 触发因果）

选了「快照 + OCR」后，点「+ 添加识别区块」就能给这款软件画一块屏幕区域，并告诉达妮娅：这块区域出现哪些字 → 触发什么。每个区块四项：

  • ·区块名：随便起，便于辨认（如「状态栏」「报错框」）。
  • ·触发类型：这次识别到后达妮娅扮演的「身份」，比如「完成 / 出错 / 建造 / 通关」，也可以填你自定义的任意中文词（英文也行）。
  • ·关键词：逗号分隔。区块里出现其中任意词即触发（如「完成, 成功, done」）。
  • ·坐标 x,y,w,h：归一化（0~1，相对整屏）。例如 0.2,0.1,0.6,0.3 = 从左 20%、上 10% 起，占宽 60%、高 30% 的一块。不确定可以先填 0,0,1,1（整屏）再调。
例子（编译软件）
区块1：名=报错框，触发=error，关键词=error, 失败, 异常，坐标=0.3,0.7,0.4,0.25 区块2：名=状态栏，触发=done，关键词=成功, BUILD SUCCESSFUL, 完成，坐标=0.2,0.05,0.6,0.08 —— 编译失败达妮娅会来安慰/调侃，成功则夸一句，平时不抢戏。

同一区块 + 同一关键词 5 秒内不重复触发，避免刷屏。没框准区域、或软件改版导致文字变了，就调坐标/关键词即可，不用动代码。

4写得好 vs 写得凑合

推荐写法（微信）
【领域关注】 聊天列表 + 右侧气泡对话，顶部是搜索和 + 号。留意他在回消息还是盯某条发呆。 【建议 / 优先级】 回消息/处理隐私时闭嘴；他主动聊才接；长时间盯一条消息发呆可关心一句。 【表达风格】 像身边的朋友，分寸自然；别把屏幕上的聊天内容念出来（隐私）。
不推荐（写成了百科）
微信是腾讯2011年推出的即时通讯软件，月活超13亿，支持文字、语音、视频、朋友圈…… —— 达妮娅看屏幕时根本用不上这段，反而占额度。

5几条小提醒

  • ·标识 ID 是合并键：和内置 ID 相同会覆盖内置条目；填一个全新 ID 就新增一条用户知识库。
  • ·把写进知识库的软件全屏后，达妮娅会切换陪伴方式，右上角弹窗会告诉你正在换上、并跟着真实连接状态走到「连上啦」再收起。
  • ·软件 / 游戏靠窗口标题里的关键词匹配；常用的没被识别，在知识库「新增一条」填上对应关键词即可。
  • ·选「快照 + OCR」的软件，必须同时配至少一个识别区块，否则和双工没区别（不会自动开口）。
  • ·不确定怎么写，就点「新增知识库」用 【领域关注】/【建议 / 优先级】/【表达风格】 三段式模板起步。
