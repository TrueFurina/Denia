# 达妮娅 · AI 桌面伴侣 —— 新用户使用指南

> 内测版 v1.0 · Windows 10 / 11（64 位）
> 一句话：**装好 → 填一个阿里云百炼 Key → 点电话图标就能说话**

---

## 一、安装（3 分钟，注意 4 个坑）

### 步骤

1. 把安装包放在**纯英文路径**下（比如 `D:\setup.exe`、桌面）
2. 双击 `达妮娅AI桌面伴侣_安装程序_v1.0_零依赖.exe`
3. 安装位置 → 填 **`D:\DanYaAI`** 这类**子目录**
4. 点「开始安装」→ 等进度条走完 → 点「完成并配置环境」
5. 配置窗口自动跑（2-5 分钟）→ 完成后自动启动

### ⚠️ 四个必须避开的坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| **装到盘根目录**（`D:\`、`H:\`、`C:\`） | 每个文件都报"访问被拒绝" | 必须建**子目录**：`D:\DanYaAI` |
| **安装包放在含中文的路径**下 | 安装器可能报错 | 放桌面或 `D:\` 根下 |
| **开着 360 / 电脑管家** | pip 装依赖被拦，卡在"核心依赖不完整" | 安装时临时关闭「文件系统防护」 |
| **Windows 蓝色警告** | 看着像病毒 | 点「**更多信息**」→「**仍要运行**」（内测版没买签名证书，正常） |

> 装完会有：桌面图标 `达妮娅AI桌面伴侣` + 开始菜单三项（启动 / 配置环境 / 卸载）

## 二、第一次启动：填 Key（唯一必须做的事）

1. 双击桌面 `达妮娅AI桌面伴侣`
2. 会看到**紫色过场动画**（光晕脉动 + 进度条），等主界面出现
3. 进入**引导页** → 粘贴你的**阿里云百炼 API Key**
4. 点 **「一键配置」** → 看到「阿里云一键已配置，3/3 就绪」
5. 选陪伴模式 → 推荐 **「云端付费」** → 点完成

### 怎么拿到 Key

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)
2. 右上角头像 → **API-KEY** → 创建
3. 复制那串 `sk-` 开头的字符

> **一个 Key 全通**：对话 / 看屏 / 语音合成 / 实时通话，全用这一把。
> 百炼每个模型有免费额度（100 万 Token 级），日常聊天+通话基本在额度内。

## 三、怎么用最好用

### ✅ 语音互动：只用「电话」图标

```
主界面输入栏 → 点 📞 电话图标 → 等"已接通" → 直接说话
```

- 走的是**云端全双工**，延迟低、能打断、音色自动用内置参考音频为你现场克隆
- **不要用**输入栏的「按住说话」按钮 —— 那是本地离线识别（ASR），**当前版本还在开发中，用不了**
- 第一次拨号会花约 2 秒克隆音色，之后秒接

### ✅ 文字聊天

直接在下框打字回车即可。支持：
- 切换角色（达妮娅 / 大肥鱼 / 自建角色）
- 长期记忆（她会记住你的偏好，跨会话保留）
- 清空对话（输入栏左侧的垃圾桶图标）

### ✅ 看屏互动

云端双工自带视觉能力，她能看到你的屏幕并主动搭话。
不想让她看 → 设置 → 视觉 → 关闭。

### ✅ 音频设备

设置 → 通话设备 → 分别选麦克风和扬声器。
- 默认是「跟随系统」，一般不用改
- 如果她说话你听不到 → 先查 **Windows 音量合成器**里「达妮娅」是否被静音

### ✅ 托盘常驻

点窗口右上角 × 不会退出，会缩到右下角托盘。右键托盘图标可以：
- 恢复主界面
- 退出程序

## 四、遇到问题怎么办

### 🔊 她说话我听不到

按顺序查：

1. **Windows 音量合成器**：右键任务栏喇叭 → 打开音量合成器 → 找「达妮娅」→ 确认不是静音、音量不是 0
2. **设置 → 通话设备**：确认扬声器选的是你正在用的那个
3. **拨号后等她说完第一句**：首次连接约 2-3 秒
4. 如果还是没声 → 设置 → 语音 → 点「试听」，看 TTS 本身能不能出声

### 🎤 我说话她没反应

1. 检查麦克风权限：Windows 设置 → 隐私 → 麦克风 → 允许桌面应用访问
2. 设置 → 通话设备 → 换一个麦克风试试
3. 说话时看界面有没有音量波动（开发者页有音频自测台）

### ⚠️ 报错「401 / Key 无效 / 没有权限」

- 去百炼控制台确认 Key 没被删、账户没欠费
- 确认开通了 `qwen-omni` 实时语音模型
- 确认账户完成了实名认证

### ⚠️ 报错「额度已耗尽 / FreeTierOnly」

- 你的账号处于「仅用免费额度」模式且该模型额度用完了
- 去百炼控制台**关闭「仅用免费额度」**或充值
- 或者等第二天额度重置

### ⚠️ 界面白屏 / 打不开

- Win10 老机器可能缺 **WebView2 运行时** → 装一下：
  https://developer.microsoft.com/microsoft-edge/webview2/
- 或者重启一次软件

### 🐢 启动很慢

首次启动会加载配置、初始化模型路由，10-20 秒正常。
之后启动会快很多（约 5 秒）。

## 六、隐私说明

- **你的 Key 只存在本机** `config.yaml`，只用于直连阿里云官方接口，不上传任何第三方
- 聊天记录 / 记忆 / 通话录音都在安装目录下，**仅本机可见**
- 卸载：Windows 设置 → 应用 → 找「达妮娅AI桌面伴侣」→ 卸载
  （`data\` 里的记忆和聊天记录需手动删）

## 八、快速自查清单

装完先按这个走一遍，能排除 90% 的问题：

- [ ] 安装位置是**子目录**（不是盘根）
- [ ] 配置窗口最后显示「✓ 核心依赖全部就绪（12/12）」
- [ ] 桌面图标双击能出**过场动画** → 主界面
- [ ] 引导页点「一键配置」显示 **3/3 就绪**
- [ ] 设置 → 语音 → **试听**能出声
- [ ] 拨号后能听到她说第一句
- [ ] 对着麦克风说话，她有反应

七项全过 = 一切正常，可以放心用。
