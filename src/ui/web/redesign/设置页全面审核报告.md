## 二、确认并已修复的问题（4 类 15 处）

### ① aria 与视觉不一致（10 处）—— 真无障碍 bug
HTML 里 10 个开关写死 `aria-checked="true"` 但 class 没有 `on`：屏幕阅读器读"开"，视觉是"关"。
后端回填前（慢网/后端抖动时）用户看到的与语义相反。逐个按后端真实默认值修正：
- 记忆库 4 开关（`enabled/semantic_search/intent_judge/inject_context` 后端默认全 True）→ `on + aria=true`，并补上缺失的「默认开」徽标（其余开关都有，唯独这组没有）
- pubjavis 系 4 开关（`fix_you_attribution`/`game_ocr_kb`/`barrage_dedup`/`barrage_quality_penalty` 默认 True）→ 同上
- agent `执行前确认`/`浏览器操作`（后端默认 False）→ `aria=false`

**修复后复测：36/36 三态一致（修前 10+1 处不一致）。**

### ② 「双工互动方法」整块被藏进开发者折叠 —— 最严重的 IA 问题
`styleSeg`（17 种互动风格）+ 提示词微调开关 + 切片数 + 主动开口强度，全部嵌在
「开发者选项（高级调参 · 普通用户一般无需改动）」折叠里 —— **核心用户控件被藏**，
违反本项目"禁藏功能"铁律（这也解释了首轮结构盘点扫不到它）。
已整块搬出，成为独立分组 `#styleGrp`「看屏互动方法 · 她看屏幕时怎么说话」
（`data-scope="both"` 永不折叠）；开发者折叠里只留 静默切换 + 量化包（确属调参）。

### ③ 546 字超长提示 + 漏了 7 种风格
原来 17 种风格的说明挤在一个 546 字的分号串里，且**漏掉 7 种**
（test3+/++/+++、test_custom/+、test4、test5 —— 按钮在但没说明，用户只能一个个试）。
已改为：日常三档一句话写在标签旁；全部 17 种收进**可折叠对照表**（折叠 38px），
每条取自 `proactive.py` 的 `_duplex_is_*` 权威 docstring，按钮 ↔ 表格 **17↔17 一一对应**。
另把「pubjavis 模式 / pubjavis+ 优化版」按钮改为中文名「开源流程对照版 / 开源流程 + 优化」
（代号保留在表格条目里，便于对照日志）。

### ④ 危险默认无警示
「执行前确认」默认 **关**（关掉后她可以直接动你的电脑，删文件跑命令都不拦），但原来没有任何
默认状态提示。已加琥珀徽标「默认关 · 建议开」并把风险写进提示语。

## 三、复核后推翻的误报（避免误修）

| 首轮报的问题 | 复核结论 |
|---|---|
| 暗色对比度 1.17（总览卡标题） | **测量方法错**：`.qk/.sc` 是半透明背景，脚本没做 alpha 合成，把浅色当成了底。合成后实际 15.63，全部 ≥4.0 |
| 隐私开关"点了无变化、无 toast" | **环境假象**：离线桩让 `togglePrivacyMode` 的 Promise 永久 pending；代码里成功/失败都有 toast，真机有后端即正常 |
| aria 不一致 36/36 | 探针判据 bug（拿中文"开/关"跟字符串 "true/false" 比）；修正后真实不一致为 10 处（已修） |
| 对照表高度 0 | 两层原因：① 我上一轮脚本把 4 个按钮写成 `class="switch on role="`（属性未闭合，解析错乱）→ 已修；② 块在高级折叠里 → 已搬出 |

## 四、检查过、判定"按预期/不动"的项

| 项 | 结论 |
|---|---|
| 760px 窄屏横向溢出 | 唯一元凶是 `.app{min-width:860px}` —— **全站共享**的桌面伴侣最小窗口宽度，刻意设计；软件窗口 ≥860px，不适用手机场景。改它会动全站布局，不动 |
| TTS / VLM / OCR 术语 | 均为行业通用缩写或模型名（Qwen3-TTS），且有中文上下文；保留 |
| pubjavis 代号 | 按钮已中文化，代号只出现在对照表（需要跟日志对数的场景） |
| 记忆库开关"点了没反应" | 同隐私开关，离线桩 pending 所致；真机正常 |
| 主动开口强度 / 切片数 | 已随互动方法一起搬出折叠（它们直接体感相关）；量化包留折叠区 |
