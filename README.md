# 达妮娅 · AI 桌面伴侣

<img src="src/ui/web/danya/av/stand.png" width="180" align="right" alt="达妮娅">

她住在这台电脑上：能听你说话、能出声、能看着你的屏幕接话，也能记住你。
不是网页里开一个标签页，而是一个**桌面上一直在**的角色。

> 当前版本 **0.2.0**（build 20261018）· Windows 10 / 11（64 位）· 仓库私有

**两条设计取舍，先说明白：**

- **本地优先**。API Key 只存在这台电脑的 `config.yaml` 里，聊天内容直接发给你选的模型服务商，
  不经过任何中转服务器。代价是你要自己准备一个 Key——所以第一版把「配 Key」从引导里删掉了，
  改成**在他真正想说话的那一刻**才出现（见下面「她还没接上大脑」）。
- **看得见的采集**。看屏不是后台偷偷截，桌宠右下角有一个点：青=正在看、琥珀=隐私模式、不亮=关着。
  网银 / 密码管理器 / 支付页面**整帧不采集**（判定在抓屏之前，不是抓完再丢）。

## 快速开始

### 路线 A · 用安装包（给测试用户）

见 [`docs/使用指南_内测版v1.0.md`](docs/使用指南_内测版v1.0.md)。里面有 4 个必须避开的安装坑
（装到盘根 / 中文路径 / 杀软拦截 / 蓝色警告），照着走能省一小时。

> ⚠️ **v1.0 安装包是旧流程**：引导页会要求粘贴 Key。仓库里的代码已经是新流程（不问 Key）。
> 两者不是同一个版本，别拿指南去对代码。

### 路线 B · 从源码跑（给开发/联调）

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
cp config.release.yaml config.yaml     # 出厂模板；里面是 ${DASHSCOPE_API_KEY} 这类环境变量引用
.venv/Scripts/python main.py --doctor  # 先自检，别等启动失败才排查
.venv/Scripts/python main.py
```

`--doctor` 在这台开发机上的基线：**16 PASS / 3 WARN / 0 FAIL**（3 个 WARN 都是开发环境专属：
配置是出厂默认但有使用痕迹 / 没有签名的 exe 入口 / 旧配置里残留「小薇」唤醒词）。

其他入口：`--no-gui` 只起控制台、`--pet-backend {auto,webview,shell}` 指定桌面壳、
`--config <path>` 换配置文件、`run_webui.py` 单开角色管理界面。

## 她还没接上「大脑」的那一下

首启只有两步：**建角色 → 体检**。不问 Key，也不摆一张表拦人。

代价是：他打完第一句话、点发送，会被挡下来。所以补偿做在**那一刻**——
输入框上方浮出一个小卡片，说清「她还没接上大脑」，两个出口（去配一个 / 稍后），
刚才那句话还留在输入框里。语音路径同样接了（副文换成「配好之后直接开口说就行」）。

为什么不做成顶部常驻条：它出现在**错误的时刻**。刚进桌面时用户没有聊天意图，看到了也不会动；
等他真想说话，眼睛早把它过滤掉了。调研的 28 个消费级产品里，没有一个靠顶部条成功的。

## 隐私与数据

- **Key**：存本机 `config.yaml`，可选 DPAPI 加密（仅本机可解）；模板里用 `${ENV_VAR}` 引用的不落盘
- **聊天内容**：直接发给你选的模型服务商，**不经过我们**（全仓外发域名里没有任何第一方服务器）
- **看屏**：敏感窗口整帧不采集；隐私模式全停；随时可在设置里关掉
- **聊天记录 / 记忆 / 通话录音**：都在 `data/`，仅本机可见，卸载时需手动删
- `config.yaml`、`data/`、`logs/`、`.venv/` 全部在 `.gitignore` 里，**从第一次提交起就没进过仓库**

## 质量是怎么守的

```bash
python tools/check_all.py     # 57 道闸门（截至 2026-10-20），约 4 分钟
```

不是「跑一遍没报错」就算过。每条闸门都做过**变异验证**：故意把实现改坏，确认它真的会红，
再还原。这一条写在 [`AGENTS.md`](AGENTS.md) 第二条里，是这个仓库最贵的纪律——
本项目抓到过的假绿至少有六种形态（断言被自己的注释满足、被同页无关代码满足、
靠残留产物通过、判据在改前改后都不存在……），每一种都是"测试全绿但功能是坏的"。

新增能力请同时补：闸门 + 变异 + CHANGELOG 明细（问题 → 改动 → 验证证据）。

### 本地跑一遍 CI 同款检查

CI 是三条腿，任一红即不通过（[`ci.yml`](.github/workflows/ci.yml)）：

```bash
python -m pip install -r requirements-test.txt   # 只装测试依赖，不装整套运行依赖
python -m compileall -q src main.py tools        # 腿 1：语法（硬门禁）
python -m pytest src/tests -q                    # 腿 2：pytest
```

腿 3 是 `src/tests` 下的**脚本式自检**，要逐个跑：

```powershell
Get-ChildItem src/tests/test_*.py | ForEach-Object { python $_.FullName }
```

它们不是 pytest 用例——`import` 阶段就会跑完整检查并 `sys.exit(1)`，混进 pytest 会让
整个收集以 `INTERNALERROR` 中断（2026-10-28 实测：55 个文件 0 个用例执行）。所以
`src/tests/conftest.py` 用 `collect_ignore` 把它们挡在外面，而不是让它们"看起来跑了"。

需要音频设备 / 桌面会话的用例（见 `ci.yml` 的 `SKIP` 列表、以及依赖 imagehash 的
`test_phash.py`）在 CI 上必然失败，刻意不跑——**它们需要在真机上验，不要靠 CI 判定**。

## 路线（诚实版）

已经明确**不做**的：本地模型、后台定时截图的默认开启、多槽配置摊开给用户。

还没定的两件（需要产品/成本决策，不是技术问题）：

1. **首启「她立刻能回话」的通道**：本地模型已排除，剩下「官方补贴若干条额度（要服务器中转 + 成本）」
   或「维持现状，靠承接浮层兜住」。
2. **看屏默认行为**：维持每 2s 定时抓帧（体验好、也最激进），还是改成「意图触发」为默认
   （她只在被叫到或明显需要时才看）。目前保留了隐私模式与敏感窗口跳过作为兜底。
