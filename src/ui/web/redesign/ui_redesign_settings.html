省钱全功能（推荐）
本地语音免费 + 游戏时云端看屏（你的阿里云 Key · 免费额度内）+ 云端记忆。一张本地模型 + 一个 Key，桌面 / 不打游戏全本地免费，打游戏自动云端顶上、不占显卡。
  • 本地：要有 NVIDIA 独显（建议 8GB+），模型跑本机、免费、离线、最隐私，但语音延迟偏高；不联网、不耗云端额度；打游戏时本地模型自动卸载。
  • 云端：走你自己绑的阿里云百炼 Key（OpenAI 兼容）。新用户每模型 100 万 Token 免费额度（90 天，仅华北2·北京地域模型享、各模型独立互不相通）；调用时自动先扣免费额度、额度内不扣费，额度耗尽且已实名则自动转按量付费。任何电脑、含无独显都能用。
  • 混搭最划算：本地语音 + 本地看屏（免费）覆盖日常；游戏 / 无独显时云端看屏顶上，云端不占本机显存。
  • 扣费＝欠费＝连累全部免费额度：任一模型溢出免费额度触发按量扣费，一旦让账户欠费（可用额度小于 0），官方明确——账户欠费时，即使其他模型仍有免费额度也无法调用。即你名下所有模型的免费额度一并被锁死。所以某模型额度用尽后绝不能继续硬用——那不是多花几块钱，是把别的模型的免费额度全搭进去。
  • 正确姿势：① 绑 Key 后把要用的模型在 90 天有效期内都用起来（免费额度按模型自动发放、互不相通）；② 某模型额度用尽后立即停用 / 停止调用，绝不停留在「用完还继续用」；③ 最省心兜底：去百炼控制台给每个要用的模型开「免费额度用完即停」（默认关），额度耗尽自动停、不转付费。额度用尽即停，比继续硬用安全得多。

桌面看屏陪伴
她盯不盯你的屏幕 —— 本地免费（默认开）/ 云端耗额度（默认关）
看屏陪伴
看屏陪伴（本地 · 免费） 默认开开=她盯着你的屏幕主动搭话（本地模型，零云端费用）；关=不主动盯屏。本地模型未下载时自动不盯屏。关它不影响你发图给她看
云端双工看屏幕（云端 · 耗额度） 默认关 · 省钱开=通话中云端双工走视频端点推屏+收声（游戏内识别/云端陪你看屏幕，更耗流量按量计费）；关（默认）=云端双工纯音频、不推流不收声，最省。本地看屏不受影响。语音通话期间无论此处开否都强制纯音频（见通话逻辑）。
重载时改用云端看屏（云端 · 耗额度） 默认关 · 省钱默认关=玩游戏 / 重负载时看屏让位，性能全留给游戏。开启=不再节流，改由云端视觉模型（VLM）持续读屏并主动搭话（花你的阿里云额度）；本地模型仍不加载、不占显卡。只影响看屏，不影响语音
开启后，高性能状态（玩游戏 / 重负载）下屏幕画面会持续发到云端由 VLM 处理，可能产生云端费用；期间不会加载任何本地模型（不占显卡）。所用模型就是「视觉模型」里当前选中的那个 —— 要换模型或填 Key，请到「模型与 API → 视觉能力」设置。
高负载自动让路
玩游戏 / 渲染等重负载时，她自动把本地模型卸下来、显卡让给前台软件；负载结束再自动挂回。这段时间她「怎么陪你」由下面两个开关决定。
高负载时自动让路 默认开开=重负载时卸载本地模型、显卡让给前台软件（不开会拖慢游戏帧数）；关=不卸载、本地模型常驻
让路时改用云端陪我 默认关 · 省钱开=重负载时不再静音，把语音切到云端双工继续陪你（消耗你的云端额度）；关=直接静音、省显存不花钱。需已绑定云端 Key才真正生效；只影响重负载期间，结束自动切回本机

云端双工共享公共容量，人多时可能排队；本地双工会占本机显存、零云占用。
云端双工 · 用户自有端点（高级 · 缓解公共端口抢不到）
公共免费端点常被占满/排队。可分别在下方填你自己的语音、视频双工网关（完整 wss URL，含 host:port 与 ?mode=）。两者都留空则用官方默认。
语音双工端点（mode=chat，纯音频·最省）
视频双工端点（mode=video，推屏·更强但更贵）
云端开销：视频双工 ≈ 音频 + 每 2s 一帧 JPEG(约 0.5fps)，算力/流量约为纯语音的 1.3~2x；纯语音只传 16k 音频，最省。不读屏时建议关掉视频双工。
没显卡也没关系 —— 自动全程走云端，不用你配置。

把记忆注入对话 默认开开=回答前带上相关记忆；关=只写不读（记了也不用）
记忆方案分类记忆=按 指令/偏好/事实 分类存放 + 检索召回（推荐）；整段摘要=旧版把对话整段摘录，只用于对比
两种方案都是本软件自研：分类记忆把长期记忆分成「指令 / 偏好 / 事实」三类存放（指令逐字保留、永远优先注入），再用语义检索按相关性召回；整段摘要是早期版本，只会把对话整段摘录、按最新排序。想对比差异时才切整段摘要。
最大条目数存满后她会自动忘掉最旧的那批

隐私模式
开启后立刻暂停屏幕与声音感知：截图 / OCR / 游戏音效 / 云端双工推流全部跳过，达妮娅拿不到新的画面与声音。适合开会、输密码、看私密内容时临时用一下；关掉即恢复。它是临时急停，不改变你的看屏设置（对比「通话与双工 → 看屏互动」）。
暂停感知（隐私模式）开=不看不听；关=恢复感知。已在游戏里双击托盘图标也能切同一个开关
专属知识（知识库）
把你自己的资料喂给达妮娅，聊天时她会参考这些专属内容回答。管理在独立的「知识库」页，设置页只做入口。
知识库集中管理文档 / 软件档案，供聊天检索
数据清理
立即生效、不可恢复。三处数据互相独立：记忆库（长期记忆）、对话记录（文字聊天历史）、知识库（你上传的资料）。清理其一不影响其余。
清空对话记录只删当前文字聊天历史，不动记忆库与知识库
社交渠道
把达妮娅接到 QQ / 微信 / QQ空间 —— 同一个大脑，跨平台聊天、记忆、性格一致
需先准备外部桥
QQ 需另跑 NapCat；微信需另跑 Gewechat(Docker)；QQ空间需你的 QQ 登录态。软件内开关只控制"连/断"，桥要你单独部署。重启软件后生效。
⚠ 本区所有开关与输入框都是「先改、再点底部「保存」才会落盘」——拨动开关后若没点保存，重启软件会恢复原样；保存后也需重启软件才生效。

启用主动互动关=她绝不主动开口（软件行为与不开此包完全一致）；开=按下方各类时机主动找你
主动时机（每类可单独关）
这些都是"你没找她"时她会主动开口的场景。关闭某一类 = 那一类不触发，其余照常。
回访关心（感冒 / 面试 / 你提过的事）你说过的事，过段时间她会问一句近况；问过即闭，除非你再说一次
宣告跟进（"我去打游戏"→"打完了？"）你说要去干嘛、半天没动静，她会问一句；只问一次
会话内跟进（聊到一半走开）聊到一半安静了，她会接一句
生活节律（饭点问吃了吗 / 熬夜关心）饭点 / 深夜还在，她会关心一句
久别问一句（长时间没找她 → "在忙什么"）你很久没来，她会随口招呼（长静默档允许问"在忙吗"）
节日 / 纪念日祝福当天首次进入、今年未用过该节日才说；既定日程
兴趣分享（抖音式：看到你感兴趣的热梗主动聊）仅在长静默 + 你确有兴趣画像时；每天最多 1 条，素材真实、不编造
安全阀（建议保持开）
LLM 审查闸（生成一句 & 另用 LLM 判可不可发）不合格会带着理由让模型重写，直到通过或到次数上限；审查器故障一律放行，不会因此闭麦
热榜素材自动刷新（喂"兴趣分享"）拉真实热搜/游戏事件当话题；涉政/灾难/八卦条目一律过滤
