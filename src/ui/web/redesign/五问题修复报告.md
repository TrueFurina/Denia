## 一、抖音：三个子问题（都有日志实锤）

### 证据（`run_20261008_005807.log`）
```

```

### 根因
1. **抖音解析失败（新情况）**：实测 `aweme/v1/web/aweme/detail` 现在返回
   `403 Blocked by ArgusSecurityPlugin Uifid Not Found`（伪造 Uifid 头 → `Signature Not Found`）。
   `Uifid` 与 `Signature(a_bogus)` 都是**页面 JS 现算**的 → 任何纯 requests 方案必然 403。
   yt-dlp 也不带匿名身份 → `Fresh cookies … are needed`。
   ⇒ 于是退回"网页摘要"，AI 拿到的只有**标题/页面文字** —— 这就是"像只看标题评价"的真相。
2. **白等 17 秒**：媒体上下文已经有了，模型仍按需裁决"要不要搜"，搜的是
   `抖音短视频 pP1ScxJEfXI 内容`，5 条结果全是 douyin.com 首页/DOU+官网 —— 纯噪声 + 拖时间。
3. **显示成"agent 操作 UI"**：前端 `app_backend.js` 里标题判据是
   `(meta.watch && !steps.length) ? '正在看' : '正在操作电脑'`；而**观看卡走到 done/error 时
   后端会把 watch 时间线写进 `meta.steps`**（`webapp._on_video_watch_progress`），
   于是 `steps.length>0` → 标题被覆盖成"达妮娅正在操作电脑 / AI 自主调用工具完成任务"。
4. **终态自相矛盾**：视频失败后 fallback 读网页，仍以 `done` + "看完了" 收尾。

### 修复
| 改动 | 文件 | 效果 |
|---|---|---|
| **新增真实浏览器解析**（Edge + CDP 旁观页面，读 `video.currentSrc` / title / duration） | `src/channels/douyin_browser.py`（新） | 免登录拿到真实直链 |
| 抖音下载改为 **HTTP → 浏览器** 两段式 | `src/channels/video_watch.py` | 浏览器成功则走完整"抽帧→VLM 看画面"链路，点评基于**真画面** |
| "一起看"链接**跳过联网搜索** | `src/companion/dialogue.py` | 省掉 ~17s 与噪声 |
| 卡片标题统一取自 `acState`（单一真相源） | `src/ui/web/redesign/app_backend.js` | 观看卡不再被 steps 覆盖 |
| fallback 终态文案诚实化 | `src/channels/media_ingest.py` | 不再"视频看不了"紧接着"看完了" |

**端到端实测**：`_download_douyin("https://v.douyin.com/pP1ScxJEfXI/")`
→ **10.3s** 拿到 `7693759455078518042.mp4`（1.18MB）+ 真实标题 + 时长 20.5s。
**卡片标题实测**：`running=达妮娅正在一起看视频 | done=达妮娅看完这个视频了 | agent=达妮娅正在操作电脑`（agent 卡不受影响）。

> ⚠️ 浏览器解析会开一次无头 Edge（~5s），已在 `finally` 里杀进程 + 删临时 profile。

## 二、开发者页跳转仍有 ~0.2s

**根因**：上一轮已修掉"入场动画重播"，剩下的就是**每次点击都现拉一次 HTML**
（`/_spa/<ts>/<file>`，服务端读文件 + 重写 `?v=`），加上等待期界面**没有任何反馈**。

**修复**（`spa.js`）：
1. **悬停预取**：鼠标移到侧栏项上就开始拉目标页 HTML（30s 内有效）。
2. **乐观高亮**：点击瞬间先把该项点亮，不等 fetch 回来。

**实测**：
| | 修复前 | 修复后 |
|---|---|---|
| 记忆库 | 33 ms | **18 ms** |
| 开发者 | 45~66 ms | **20 ms** |

## 三、档位切换未持久化（重启回纯本地）

**根因（两处叠加）**：
1. **档位只存在浏览器**：`setOperationMode()` 只写 `localStorage.daniya_operation_mode`，
   后端 config 的 `companion_features` / `companion_mode` **从未被更新**。
   实测 `config.yaml`：`companion_features` 只有 `[local_vision, long_memory]`，
   `companion_mode` **整个键缺失** → 后端按自己的（旧）配置启动 = 纯本地。
2. **读路径不认新词**：`getOperationMode()` 只接受旧四档名，三档 token（local/cloud/mixed）
   一律回 `'all'`（界面退成"未设置"）。

**修复**（`ui_redesign_settings.html` + `webapp.py`）：
- 换档时**同时把该档预设功能集写回后端**
  （local→`local_duplex+local_vision+long_memory`，cloud→`cloud_duplex+long_memory`，
  mixed→`local_duplex+cloud_snapshot+long_memory`，与 `webapp.PRESET_FEATURES` 一字不差），
  后端据此写 `companion_mode`、反推引擎配置并热切换；并取消功能集编辑器的防抖保存，避免互相覆盖。
- 启动时**以后端为准恢复档位**（新增 `get_companion_features().mode3` =
  由 `companion_features` 推导的三档，不再依赖可能缺失的 `companion_mode` 字符串）。
- `getOperationMode()` 两套词汇都认；`highlightMode()` 经 `LEGACY_MODE` 归一。

**实测**：点「混合」卡 → `saveCompanionFeatures` 收到
`[{local_duplex},{cloud_snapshot},{long_memory}]`（正是后端 mixed 预设）+ `localStorage='混合推荐'`。

## 四、纯本地不自动连接本地模型

**根因**：`webapp.warm_local_model()` 的闸门是
```python
if "local_duplex" not in fids or str(pro_raw.get("duplex_mode")) != "local_omni": 跳过
```
而配置里 **`proactive.duplex_mode` 这个键根本不存在**（`str(None)='None'`）
→ 永远提前返回"当前模式不需要本地模型暖机" → 本地模型永不自动挂载。

**修复**：改以**功能集为主**判意图 —— `local_duplex ∈ features` 即表示用户要本地双工；
`duplex_mode` 只用于排除"明确切到云端/关闭"（缺失/auto/true 都算本地意图）。
并在返回的 reason 里带上 `duplex_mode=... local_duplex=...`，下次一眼可诊断。

**另**：档位与功能集不一致的**历史脏数据**（档位是本地侧、features 却缺 `local_duplex`）
会在设置页加载时**自愈**：只补不改（补上该档预设，不动云端档、不移除任何已选功能），
并提示"档位与功能集已对齐"。

## 五、搜索升级（接入开源做法）

**旧算法**：`textContent.indexOf(q) >= 0` 就算命中，**不排序**、不做相关性区分。

**新算法**：移植 **fzf** 的打分规则（命令面板类 UI —— VS Code / Raycast / Linear / cmdk 都这一路）：
1. 整段子串 > 跳字模糊（模糊分上限 59，永远低于最差子串分 60）；
2. 命中在**开头/分隔符后（词首）**加分；越靠前越好；文本越短（越精确）越好；
3. 连续命中加分、跳字扣分（拉丁/数字支持 `vrm`→`vision_router_model` 这类子序列）；
4. **中文只认整段子串**（逐字模糊对中文没意义，只会把"云端/本地"拆开误命中）；
5. 字段权重：标题 1.0 / 控件标签 0.72 / 正文 0.18（正文默认不参与）。

**同义簇收紧**：把 `local/cloud/mixed/vision/snapshot/duplex/realtime` 等 token 收进来；
**刻意剔除过于通用的词**（如把 "模式" 从「档位」簇移除 —— 否则搜 `cloud` 会先看到"深浅模式"）。

**实测**：
| 查询 | 结果 | 备注 |
|---|---|---|
| `显存` | 1 项 = **显存预算** | 精确 |
| `克隆` | 1 项 = **语音模式** | 精确 |
| `音色` | 4 项（语音模式 / 双工语音互动 / 双工 / 模型一览） | 相关词扩展 |
| `cloud` | 4 项（含**档位**） | 英文 token 可搜 |
| `1` / `1.2.3` / `16` | **0 项** + 专门提示 | 不再误命中正文数值 |
| `zzzznope` | 0 项 + 「猜你想找」 | |
