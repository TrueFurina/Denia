本地双工 M1（真双工·免费但高延迟）最吃显存
达妮娅常驻你电脑、永远在线、随时接话。语音焊死固定音——想换成达娅声需走云端克隆或挂 RVC 变声（轻量，可共存）。

不开双工时也能"看屏幕"：每几秒截一帧理解画面（非真双工）。8GB 卡也跑得动。
本地语音克隆 · 千问 Qwen3-TTS（GPU）≈2.5 GB
零样本克隆达娅声，免费、零 key、零云。本地克隆音色偏平、像真度一般，要好听的达娅声建议走云端 TTS（百炼 / MiMo 克隆）；纯聊天时 GPU 空闲可共存，和双工同开建议用 Q4 档或让它走 CPU（会慢一点）。
