03 · PRIVACY & DATA

你的对话，不经过我们

这不是一句承诺，是架构决定的：全仓外发域名里没有任何第一方服务器。我们没有你的聊天记录，因为那些数据根本没往我们这儿发。

01
API Key 只存在这台电脑上 写在本地 config.yaml，可选 DPAPI 加密（只有这台机器能解）。模板里用环境变量引用的 Key 不落盘。
02
聊天内容直连你选的服务商 没有中转服务器，没有转发层。你付给模型商的钱，不经我们的手，我们也不抽成。
03
看屏前先判定，不是抓完再丢 网银 / 密码管理器 / 支付页面在抓屏之前就整帧跳过。桌宠右下角有一个点：青=正在看、琥珀=隐私模式、不亮=关着。
04
卸载了也能带走 聊天记录、记忆、通话录音都在本地 data/。记忆可导出 Markdown——公司不在了，你的十年对话还在你的硬盘上。
05
敏感文件从第一次提交起就没进过仓库 config.yaml / data/ / logs/ / .venv/ 全在 .gitignore 里。打包脚本还会二次核对，混进隐私文件就直接删包。

变异测试的意义

变异刀会故意把代码改成错的，看闸门会不会红。不红的闸门等于不存在——这是防「假绿」，不是防「报错」。

06 · INSTALL

安装：四个坑，照着避开能省一小时

这四个都是真实撞过的，不是预防性提醒。

01
不要装到盘根装 D:\ 根目录会出路径拼接问题，装到 D:\Denia 这样的子目录。
02
中文路径建议避开某些链路对中文路径处理不稳，装到纯英文目录最省事。
03
杀软可能误报未签名的自编译 exe 常被 360 / 火绒 / Defender 拦。加入信任区即可。
04
蓝色警告不是病毒SmartScreen 对未签名程序的默认提示，点「更多信息 → 仍要运行」。

安装版：双击，跟着向导走

装完自动创建快捷方式。第一次启动会做一次自检（doctor），把缺的东西直接告诉你该装什么、用什么命令装。

首启：建角色 → 体检

只两步。不问你要 API Key——Key 在你真想说话的那一刻才会出现，一个小卡片浮在输入框上方，两个出口：去配一个 / 稍后。

源码包：建环境

python -m venv .venv → .venv/Scripts/pip install -r requirements.txt → .venv/Scripts/python main.py --doctor（先自检，别等启动失败才排查）→ .venv/Scripts/python main.py

想要真透明桌宠：装 Electron 壳

cd shell && npm install（本机 npm install 后约 383MB；实测 381MB）。不装也能跑，但桌宠窗口只能显示、点不到也拖不动——这是 pywebview 的宿主限制，日志会如实告诉你。

07 · NOTICE

授权与声明

📋 使用边界

  • 开源协议：MIT。可自由使用、修改、分发。
  • 模型费用：BYOK，用自己的 API Key，费用直接付给模型服务商，本项目不抽成、不经手。
  • 不做本地模型：下 1–2GB、首 token 数秒，陪伴类的第一句话就冷场——这是明确的设计取舍，不是没做完。
  • 数据责任：聊天记录与记忆存在本机 data/，请自行备份；卸载时需手动删除。

🤝 关于本项目

  • 定位：本地优先的 Windows 桌面伴侣。不是一个平台，是这一个角色。
  • 为什么本地优先：云端陪伴的单位经济学不成立——头部产品月运营支出千万美元级，年收入远低于此，最终只能卖身。本地运行 + 用户自担成本，是唯一能长期存在的结构。
  • 调研基础：横跨 4 类阵营、28 个消费级产品的对比拆解。
  • 反馈：见页面底部仓库 Issue。
