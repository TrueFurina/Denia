本地语音免费 + 游戏时云端看屏（你的阿里云 Key · 免费额度内）+ 云端记忆。一张本地模型 + 一个 Key，桌面 / 不打游戏全本地免费，打游戏自动云端顶上、不占显卡。
  • 本地：要有 NVIDIA 独显（建议 8GB+），模型跑本机、免费、离线、最隐私，但语音延迟偏高；不联网、不耗云端额度；打游戏时本地模型自动卸载。
  • 云端：走你自己绑的阿里云百炼 Key（OpenAI 兼容）。新用户每模型 100 万 Token 免费额度（90 天，仅华北2·北京地域模型享、各模型独立互不相通）；调用时自动先扣免费额度、额度内不扣费，额度耗尽且已实名则自动转按量付费。任何电脑、含无独显都能用。
  • 混搭最划算：本地语音 + 本地看屏（免费）覆盖日常；游戏 / 无独显时云端看屏顶上，云端不占本机显存。
  • 扣费＝欠费＝连累全部免费额度：任一模型溢出免费额度触发按量扣费，一旦让账户欠费（可用额度小于 0），官方明确——账户欠费时，即使其他模型仍有免费额度也无法调用。即你名下所有模型的免费额度一并被锁死。所以某模型额度用尽后绝不能继续硬用——那不是多花几块钱，是把别的模型的免费额度全搭进去。
  • 正确姿势：① 绑 Key 后把要用的模型在 90 天有效期内都用起来（免费额度按模型自动发放、互不相通）；② 某模型额度用尽后立即停用 / 停止调用，绝不停留在「用完还继续用」；③ 最省心兜底：去百炼控制台给每个要用的模型开「免费额度用完即停」（默认关），额度耗尽自动停、不转付费。额度用尽即停，比继续硬用安全得多。

QQ 需另跑 NapCat；微信需另跑 Gewechat(Docker)；QQ空间需你的 QQ 登录态。软件内开关只控制"连/断"，桥要你单独部署。改动后需重启软件生效。
陪你看视频（桌面聊天框也能用）
在软件内聊天框、QQ、微信里发 B站 / 抖音 / YouTube 等视频链接，达妮娅会取原视频、抽帧观看，然后和你一起讨论。这是桌面聊天框的核心陪伴能力，无需任何外部桥（需联网 + yt-dlp）。
