# 达妮娅 · AI 桌面伴侣（内测版 v0.9.0）

> 一个住在你电脑里的 AI 伴侣。聊天、语音通话、看屏幕陪你——全部走你自己的阿里云百炼 Key。

---

## 一、快速开始（3 步）

### 1. 安装
双击 `达妮娅AI桌面伴侣_完整安装包.exe` → 按向导下一步 → 装完自动创建桌面图标。

**安装要求**
- Windows 10/11（64 位）
- **Python 3.12**（安装时自动检测，没有会给出下载链接）
- 安装包**请放在纯英文路径**下再双击（如 `D:\setup.exe`）。放在含中文的目录里，Windows 安装器可能报"拒绝访问"

### 2. 首次启动
双击桌面 **`达妮娅AI桌面伴侣`** → 会进入**引导页**。

### 3. 填你的阿里云百炼 Key（唯一必须做的一步）
1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/) → 右上角「API-KEY」→ 创建
2. 把 Key 粘贴进引导页的输入框
3. 点 **「一键配置」** —— 一个 Key 自动接通全部能力：**对话 / 看屏 / 语音合成 / 实时通话**
4. 选陪伴模式（推荐 **「云端付费」**）→ 完成引导

> **推荐配置就是「阿里云一键全通」**。一把百炼 Key 打通四路，每个模型都有免费额度（100 万 Token 级），日常用基本不花钱。

## 二、功能说明

### ✅ 已可用

| 功能 | 说明 |
|---|---|
| **文字聊天** | 主界面输入框直接聊，支持多角色切换、长期记忆 |
| **语音通话（云端双工）** | 点输入栏「电话」图标 → 拨通后**像打电话一样**说话，她实时回应。<br>音色自动用内置参考音频为你的 Key 现场克隆（首次约 2 秒） |

| **多角色** | 内置达妮娅、大肥鱼；可新建角色、换头像/立绘/背景 |
| **长期记忆** | 记住你说过的偏好，跨会话保留（可在设置里清空） |

| **音频设备** | 麦克风/扬声器可自由切换，自动适配设备采样率（不变音） |

## 三、常见问题

**Q：一定要阿里云百炼吗？**
推荐用，因为一把 Key 全通。也支持 DeepSeek / 智谱 / OpenAI 兼容端点等，但需要分别配置。

**Q：会花很多钱吗？**
百炼每个模型都有免费额度（通常 100 万 Token / 90 天）。日常聊天+通话基本在额度内。超出后按量计费，很便宜。语音复刻本身**免费**，只在合成时计费。

**Q：装完双击没反应 / 报"拒绝访问"？**
1. 确认安装包在**纯英文路径**下
2. 关掉 GamePP、显卡超频工具等会注入进程的软件再装
3. 如果弹出 Windows SmartScreen 蓝色警告 → 点「更多信息」→「仍要运行」（内测版未购买代码签名证书，属正常现象）

**Q：她说话听不到？**
1. 检查 Windows 音量合成器里本程序是否被静音
2. 设置 → 通话设备 → 确认扬声器选的是你在用的那个
3. 通话中右键任务栏音量图标 → 打开音量合成器 → 把「达妮娅」拉满

**Q：卸载？**
Windows 设置 → 应用 → 找到「达妮娅AI桌面伴侣」→ 卸载。程序文件、虚拟环境、日志会一并清除；`data/` 下的记忆和聊天记录需手动删除。

## 四、数据与隐私

- **Key 只存在你本机的 `config.yaml`**，不会上传到任何第三方服务器（只用于直连阿里云官方接口）
- 聊天记录、记忆、通话录音都在安装目录 `data/` 与 `src/ui/web/assets/chat_audio/` 下，**仅本机可见**
- 卸载后可手动删除整个安装目录彻底清除
