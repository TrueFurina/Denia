# 闸门「假绿」形式清单

> 2026-11-10 整理。来源：一天里对 6 道「没有变异刀」的特性判据门的逐刀体检，
> 共发现 12 处缺口，全部属于「门是绿的，但门后面的东西没被测到」。
>
> **一句话判据**：一道门只有在「把 bug 塞回去它必须变红」时才算存在。
> 全绿不算，CI 通过不算，判据条数更不算。

---

## 怎么用这份清单

1. 给门配一把刀（见文末骨架），确认它**能红**；
2. 红的时候确认它**点名了指定的那条判据**（不是「随便红一个」）；
3. 逐条对照下面十种形式体检断言写法；
4. 把修好的门登记进 `tools/check_all.py`，让刀常驻。

---

## 十种形式

### 1. 判据从被测代码里读出来

**症状**：测试去读被测源码，用读到的结果决定「该断言什么」。

```python
def _guards_cfg(method_name):            # 测试自己去源码里找守卫
    return "if not self._cfg" in body

if _guards_cfg(nm):                      # ← 用它决定要不要断言
    assert result["success"] is False
else:
    pass                                 # ← 删掉守卫 ⇒ 判据自动消失
```

**为什么最狠**：别的洞是「判据太松」，这个是「判据会自己消失」。删掉产品里的守卫，
测试跟着一起放弃断言，全绿。

**修法**：把口径从代码里搬出来（手写契约表 `CFG_GUARDED` / `CFG_FREE`），
源码只用来**核对一致性** —— 删守卫时那条核对断言会红。

---

### 2. 只写一侧

**形式 A · 只有上界**

```python
assertLessEqual(turns, 1)     # turns=0 也满足
```

**形式 B · 只有负向**

```python
ok("关闸时不分析", va.calls == 0)      # 函数整个坏成 return 也绿
ok("关闸后返回 None", r is None)        # LLM 桩坏掉也返回 None
```

**修法**：配正控（开闸时必须发生），配下界（必须真的记过一轮）。
**判据要同时守住「发生了」和「没发生」。**

---

### 3. 链路没启动，量的不是被测对象

```python
bus = EventBus(); rep.subscribe(); rep.start()
await bus.publish(AI_DECISION)     # publish 只是 queue.put
dt = time.time() - t0; assertLess(dt, 0.5)
```

派发靠 `bus.run()`，这里从头到尾没跑 → 两个事件没被任何 handler 处理过。
「判定没启动」和「判定很快」读数完全一样 —— 它量的是入队耗时。

**修法**：先把链路真的跑起来（`ensure_future(bus.run())`），再断言行为；
并且补一条「2.5s 后判定必须落盘」的正控。

---

### 4. 跳过 / 吞异常当通过

```python
except Exception as e:
    print(f"  ! 跳过…（导入失败: {e}）")     # ← 不计 FAIL
```

实测：让 `synthesize` 抛一个非 `RuntimeError`，整段（落盘/异常类型/工厂）消失，
判据 30 → 27 条，闸门仍然 exit 0。

**修法**：
- `except` 里必须 `check(..., False)`，并带上真实异常类型；
- 末尾加**判据总数下限护栏**，任何段被跳过都会红：

```python
BASELINE_CHECKS = 31
check(f"判据总数不低于基线（{BASELINE_CHECKS}）", PASS + FAIL + 1 >= BASELINE_CHECKS)
```

---

### 5. 观察窗口 < 被测周期

```python
# 轮询间隔 3.0s
cfg...interval_s = 3.0
await asyncio.sleep(0.6)          # ← 这段里循环本来就在 sleep
assert after == before            # 「不再抓屏」在任何实现下都成立
```

**修法**：把周期压到远小于窗口（如 `0.05s`），让窗口覆盖十来轮；
或者改成事件驱动式断言。

**规矩**：异步/轮询类判据，**观察窗口必须大于被测周期**。

---

### 6. 依赖本机私有文件

```python
cfg_real = yaml.safe_load((ROOT / "config.yaml").read_text())   # 在 .gitignore 里
```

新克隆上 `FileNotFoundError` → 判据记 False → **这道门在任何新克隆上都是红的**。
CI 之所以绿，是 self-check job 先「prepare standard first-run layout」造了它。

**修法**：缺文件回落出厂模板（`config.release.yaml`），并在判据名里标明数据源：

```python
_cfg_path = ROOT / "config.yaml"
if not _cfg_path.is_file():
    _cfg_path = ROOT / "config.release.yaml"
```

---

### 7. 只覆盖生产端，没走到事故现场

门是为某次事故写的，但断言只落在**生产端**（payload 字段对不对），
而事故在**消费端**（下游怎么用这个 payload）。

```python
# 21 条判据全在验 payload
assert d["to_chat"] is True and d["is_proactive"] is False
# 而当年那个 bug 在 webapp：
if bool(d.get("is_proactive")) or bool(d.get("to_chat") is False):
    return     # ← 改回「只看 is_proactive」，21 条照样全绿
```

**修法**：写测试前先问一句 ——
**「当年这个 bug 如果回来，它落在哪个文件、哪一行？我的断言有没有碰到那一行？」**
够不到运行时就补静态接线断言（源码字符串 / AST）。

---

### 8. 只验返回值，不验副作用

```python
r = api.set_mixed_mode({"enabled": True})
ck("老调用仍走原路径", r.get("success") is True and r.get("atomic") is not True)
ck("老调用不碰双工/不写盘", api._duplex_calls == [] and _Cfg.writes == 0)
```

两条只证明「返回 success」+「没副作用」。实现改成
`return {"success": True}`（根本不调下游）**照样全绿**。

**修法**：断言副作用确实发生（`("set_mixed_mode", True) in api._proactive.calls`）。

---

### 9. 断言恒真：断言了两次 `not False`

```python
self.reached_decision = False      # __init__ 里
self.reached_emit = False          # 全文件没有任何地方置 True
...
ok("安全返回不触发", (not m2.reached_decision) and (not m2.reached_emit))
```

**修法**：换成可观测的真实调用面（打模块补丁 spy 目标函数，断言调用次数）。
**任何「标志位」断言，先 `grep` 一遍它有没有被置 True 的地方。**

---

### 10. 前提消失按通过计

```python
if cold_arch:
    ok("B6 冷落+原型不主动 → 拒", ...)
else:
    ok("B6 …跳过（无此类原型）", True, "skip")     # ← 前提没了算通过
```

原型表一变，B6 就永久通过，而它守的闸门一次都没验过。

**修法**：把前提本身也变成一条判据（`cold_arch is not None`），前提消失就红。

## 五个可复制的句式

```python
# ① 正控：开闸时必须真的发生
check("开闸时 capture_now 真的进入抓屏流程", cap._event_trigger_count == 1)

# ② 上界 + 下界
check("重复投递只记一轮", turns <= 1)
check("且必须真的记过一轮", turns >= 1)

# ③ 观察窗口 > 周期
cfg.interval_s = 0.05          # 被测周期
await asyncio.sleep(0.6)       # 窗口 ≈ 12 轮

# ④ 跳过即红
except Exception as e:
    check(f"[3] 段必须真的跑完（不得静默跳过）：{type(e).__name__}: {e}", False)

# ⑤ 静态接线（够不到运行时的时候）
check("webapp 分道判据仍读 to_chat",
      'bool(d.get("to_chat") is False)' in webapp_src)
```

## 变异刀最小骨架

```python
"""变异刀：<门名>。判据 = 退出码非 0 **且** 指定判据被点名 **且** 还原 sha256 一致。"""
import hashlib, io, os, subprocess, sys

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
PY = sys.executable
GATE = os.path.join("tools", "test_xxx.py")

MUTS = [("A <破坏描述>", "src/xxx.py", lambda t: t.replace(OLD, NEW), "<必须被点名的判据片段>")]


def sha(p):
    with open(p, "rb") as f:
        return hashlib.sha256(f.read()).hexdigest()


def run_gate():
    p = subprocess.run([PY, "-u", GATE], cwd=ROOT, capture_output=True, text=True,
                       encoding="utf-8", errors="replace", timeout=900)
    return p.returncode, (p.stdout or "") + (p.stderr or "")


def main():
    rc, out = run_gate()
    if rc != 0:
        print("起点不绿 → 后面的红都不可信")
        return 1
    bad = []
    for name, rel, fn, must in MUTS:
        path = os.path.join(ROOT, rel)
        original = open(path, "rb").read()
        h0 = hashlib.sha256(original).hexdigest()
        text = io.TextIOWrapper(io.BytesIO(original), encoding="utf-8", newline="").read()
        try:
            mutated = fn(text)
            assert mutated != text, "锚点失效"
            open(path, "wb").write(mutated.encode("utf-8"))
            rc, out = run_gate()
        finally:
            open(path, "wb").write(original)
        ok = rc != 0 and (must in out) and sha(path) == h0
        print(("✓ " if ok else "✗ ") + name)
        if not ok:
            bad.append(name)
    print("MUTATION_RESULT:", "ALL PASS" if not bad else bad)
    return 0 if not bad else 1


if __name__ == "__main__":
    sys.exit(main())
```

**三条验收口径**：
1. 起点必须绿（否则后面的红全部不可信）；
2. 每把刀都要**点名**指定判据，不接受「随便红一个」；
3. 还原后 sha256 必须逐字节一致，否则刀本身在污染工作区。

## 一条元规矩

> **没有失败 ≠ 检查过。**

所以每道门请自带一个**可数、有下限**的判据总数护栏。
它与上面十条互补：十条治「判据写错」，护栏治「判据跑不到」。
