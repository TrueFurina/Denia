用来把「她听不见我 / 我听不见她」查死：① 麦克风选一路 → 点开始 → 对着说话， 看律动条是否跳动（跳动=这一路真的在采你的人声）；② 扬声器选一路 → 点播放， 测试音会从那一路设备出来（没响就是那一路在你机器上不出声）。 两处都会回显后端**实际解析到的索引 / host API**，所以"选了 A 却响在 B"也一眼可见。
